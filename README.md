# Intune-device-management-lab
Implemented a Microsoft Intune Endpoint Management lab featuring Windows Autopilot enrollment, application deployment, compliance policies, BitLocker encryption, security baselines, and Windows Update Rings. Demonstrated modern endpoint management, device security, and cloud-based administration using Microsoft Intune, Entra ID, and Microsoft 365.

Project Overview
